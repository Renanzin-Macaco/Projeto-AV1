# 🛍️ Vesteza — Catálogo de Produtos

**Vesteza: Roupas e Acessórios**

Projeto desenvolvido em React com o objetivo de criar um catálogo de produtos com carrinho de compras, permitindo adicionar produtos, controlar suas quantidades, remover itens e calcular o valor total da compra.

## 📌 Sobre o Projeto

O projeto consiste em uma loja virtual simples de roupas e acessórios.

O usuário pode visualizar os produtos disponíveis, adicionar itens ao carrinho e controlar a quantidade de cada produto.

O projeto foi desenvolvido como prática dos principais conceitos do React, como:

- Componentes reutilizáveis
- Props
- Estado com `useState`
- Renderização de listas com `.map()`
- Busca de elementos com `.find()`
- Remoção de elementos com `.filter()`
- Cálculos com `.reduce()`
- Eventos com `onClick`

## ⚙️ Funcionalidades

- Exibição de produtos com:
  - Nome
  - Imagem
  - Preço
  - Descrição
- Componente reutilizável para cada produto
- Adição de produtos ao carrinho
- Aumento da quantidade de produtos
- Diminuição da quantidade de produtos
- Remoção de produtos do carrinho
- Cálculo da quantidade total de itens
- Cálculo do valor total da compra
- Mensagem informando quando o carrinho está vazio
- Interface responsiva e estilizada
